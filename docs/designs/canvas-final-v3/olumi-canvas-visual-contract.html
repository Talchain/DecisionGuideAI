03Visual grammar

One meaning per visual channel. Nothing relies on colour alone.

Connections express causal beliefs

Structural links from exploration to alternatives, and alternatives to their factor targets, stay quiet and grey. Their thickness is not a causal effect. A solid line alone does not prove a relationship is established.

Icons make the next reasoning move accessible

An unmarked element is not “verified”. Show useful exceptions, not the same provenance mark everywhere. A named behavioural check requires a grounded finding mapped to that element.

Implementation notes, source precedence and data gates

What this reference settles

Screen-space targets: anchors 460 × 65; option width 248; factor width 248; outcome/risk width 248. These are reference dimensions at 100%, not permission to override layout minima or semantic-zoom transforms. Resting cards stay bounded; opening an inspector does not enlarge them. Keep full labels and values accessible through focus/click as well as hover.

What it reuses

Existing movable inspectors, selection/path focus, typed edit routes, provenance readers, the coaching resolver and current science outputs. The mock inspector and right-panel content illustrate routing only, not a new panel design.

Precedence over the older v2

Use the 23 September rulings: strength/magnitude controls edge width before and after analysis; no new dotted certainty tier; AI sign disagreement is not human contest; retain valid historical figures with Last run · when a model change is known. Never-run or cannot-confirm states must not invent a past analysis.

Still requires the usual release checks

Canonical editing integrity, exact-head review, production geometry and browser accessibility. This file is not a merge instruction. New creative treatments in section 04 remain proposals until Paul approves them.

Fixture gates. Every number, evidence reason and derived ranking in the reference is an illustrative fixture. In production: driver rank/denominator come from the licensed reader; a relative bar is not a causal contribution percentage; a turning point requires a real found threshold with compatible units; a range is not a confidence interval unless the producer says it is. Prior ranges displaced by a user-stated value remain disclosed as superseded, not plotted as active uncertainty.

Coaching and attention. Attention is a prioritised presentation of existing grounds, not a new scientific score. Show at most a few meaningful focus points, with visible blocking states separate from that budget. Behavioural science explains why a question may help; it never diagnoses a person. A local read or click does not validate an estimate. Coaching opens the existing AI surface with element context and a pre-filled question; it does not send or mutate silently.

Option and outcome limits. The main graph deliberately shows no per-option outcome trade-off chart. Only supplied, scoped results may be added. Outcome/risk records are distinct from the strength of their connections. Probability of a goal, support for an option and confidence in a connection must never stand in for each other. Do not advertise unsupported risk/outcome editors.
