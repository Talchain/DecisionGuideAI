# Olumi Field prototype

Disposable, fixture-only design experiment. It does not import, mount or modify the production Olumi application.

Open `index.html` directly in a browser, or serve the repository root with any simple static server and visit:

`/docs/Design/experiments/olumi-field-prototype/`

Designed and frozen as an independent concept at 1440 × 900, with a 1280 × 800 laptop sanity check.

Use the top-right tour to jump cleanly among states A–G. Select **Review board** for the disposition board, 18-item proposed-removals gallery, capability map and frozen rationale.
