# New-look functional test slice

Run only from this worktree. `build.sh` uses the repository's Vite config with automatic environment-file loading disabled. `serve.ts` serves only 127.0.0.1:4132 and the required dist; its Service reads `.night-data/<tag>/olumi.db` copies, never the source databases. Authentication is reissued only on each copy, kept in browser memory, never written to link files. The caller is an offline throwing function; no provider adapter is used. Browser requests to any other origin and unlisted mutations are refused.

`browser.sh` acquires the machine browser lock, removes only an empty lock older than 20 minutes, and invokes heavy.sh. `capture.mjs` records the approved funding board and pending first model at 2000×1200, 1128×707 and 1504×902 CSS pixels at DPR 1.33 (2000×1200 image). It opens without zoom rescue and exercises the page's pan cue. `sheet.py <item>` puts every capture next to the matching target at the same pixel scale.

The targets are composites. A snapshot cannot establish the whole journey or the validity of a finding. The OUT file records observed states, POST receipts and limitations separately.
